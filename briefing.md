## 2. Critical Infrastructure & ICS Threat Landscape

* **[UPDATE] Extortion Group n0n Mounts Coordinated Campaign Against 38 Maritime Port Operators:** Financially motivated cyber extortion group n0n indexed data stolen from 38 global maritime, container, and port logistics entities across 18 countries onto its Tor leak repository, as revealed by [Industrial Cyber](https://industrialcyber.co/ransomware/n0n-extortion-claims-target-38-global-maritime-and-logistics-organizations-raising-port-data-exposure-concerns/). Demanding ransoms ranging from $2.4 million to $14 million, the group published operational Electronic Data Interchange (EDI) message streams, container manifests, and terminal system configurations from key transshipment hubs, including South Korea’s Pusan Newport Company and Vietnam’s Nam Dinh Vu Port, pointing to an initial compromise of a shared maritime logistics application.
* **CISA Flags Zero-Days in Edge Routing and Industrial Perimeter Appliances:** The US Cybersecurity and Infrastructure Security Agency (CISA) added four actively weaponized vulnerabilities to its Known Exploited Vulnerabilities (KEV) catalog, headlined by CVE-2026-0322 (CVSS 8.6)—a critical code injection flaw in the management interface of Palo Alto Networks PAN-OS software permitting authenticated remote code execution, detailed by [CISA](https://www.cisa.gov/news-events/alerts/2026/10/14/cisa-adds-four-known-exploited-vulnerabilities-catalog), [SecurityWeek](https://www.securityweek.com/palo-alto-networks-patches-pan-os-zero-day-exploited-for-remote-code-execution/), and [BleepingComputer](https://www.bleepingcomputer.com/news/security/palo-alto-networks-warns-of-pan-os-rce-flaw-exploited-in-attacks/). Also added was CVE-2026-76519, an unauthenticated arbitrary file-write vulnerability in Cisco Secure Email Gateway (SEG) that allows remote attackers executing crafted SMTP attachments to run code with root privileges.
* **Critical Flaws Exposed in CISA Malcolm Network Traffic Analysis Architecture:** CISA issued an industrial advisory detailing six vulnerabilities (CVSS scores up to 8.1) in its Malcolm suite—an open-source network traffic analysis tool widely used across Energy, Water, and IT sectors, according to [CISA Advisories](https://www.cisa.gov/news-events/ics-advisories/icsa-26-280-01). The flaws (including CVE-2026-107336 and CVE-2026-107333) expose front-end reverse proxy misconfigurations that allow unauthenticated threat actors to forge client authentication headers, bypass role-based access controls, and execute arbitrary server-side requests via the underlying Arkime packet capture engine.
* **Authentication and Memory Exhaustion Bugs Imperil Eclipse Milo Industrial OPC UA Servers:** A security bulletin disclosed five vulnerabilities in the Eclipse Milo open-source OPC UA implementation, an operational technology communications framework deployed across chemical and power plants, detailed by [CISA Advisories](https://www.cisa.gov/news-events/ics-advisories/icsa-26-288-01). The most severe issues—CVE-2026-62927 (CVSS 7.5/8.7) and CVE-2026-58080—allow low-privileged or anonymous clients to bypass authorization routines, invoke protected engineering methods, or exhaust pooled direct memory through unreleased message fragments, causing industrial host termination.
* **FERC Discloses Cybersecurity Compliance Deficits Across Bulk Power Generation:** The Federal Energy Regulatory Commission (FERC) published its fiscal 2026 audit analysis identifying vulnerabilities in the US electrical power sector under NERC CIP-002-5.1a, reported by [Industrial Cyber](https://industrialcyber.co/utilities-energy-power-water-waste/ferc-identifies-cybersecurity-compliance-gaps-in-us-power-sector-flags-risks-from-ai-tools-and-third-party-control-systems/). The report highlighted widespread delays in evaluating inverter-based renewable resources, failure to map third-party contractor telemetry controls into medium-impact Bulk Electric System (BES) tiers, and uncontrolled access paths created by enterprise artificial intelligence automation tools integrated into operational engineering networks.
* **Slovak Nuclear Grid Synchronizes Mochovce Unit 4, Expanding Regional Baseload Capacity:** Slovenské Elektrárne connected a 471-megawatt reactor unit to the Central European electrical grid at Mochovce, operating initially at 20 percent capacity, as reported by [Portfolio](https://www.portfolio.hu/befektetes/20261015/az-unio-rekordere-lett-a-szomszedos-orszag-halozatra-kotottek-az-uj-atomblokkot-870040). ## 5. Recommended Deep Dives

* **Implementation of Zero-Trust Network Controls on Edge Email Gateways:** Enterprise defense architectures must immediately verify Cisco Secure Email Gateway (CVE-2026-76519) firmware. Because unauthenticated actors can overwrite files with root privileges via crafted MIME payloads, security teams should isolate appliances, inspect MTA root system logs for irregular file generation, and restrict interface management access strictly to out-of-band management VLANs.
* **Audit and Segmentation of In-Store Building Management Systems (BMS):** Facilities teams and retail logistics providers should immediately conduct operational sweeps of Emerson Copeland, Dixell, and Danfoss refrigeration hardware. Enforce segmented OT-only VLAN architecture, revoke public internet connectivity for BMS hubs, and configure alerting to flag out-of-bounds refrigeration and defrost setpoint overrides.
* **Enterprise Ad-Blocking and Network Scrubbing Against AdFection Threat Vectors:** To mitigate zero-click drive-by exploitation delivered via ad platforms (as demonstrated by Discover-Tech/Candiru), corporate system administrators should enforce enterprise DNS-level ad blocking and restrict untrusted third-party advertising iframes across corporate workstations, particularly on devices utilized by legal, investigative, and executive personnel.
