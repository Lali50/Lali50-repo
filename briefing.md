## 2. Critical Infrastructure & ICS Threat Landscape

* **[UPDATE] Danfoss BMS Authentication Design Flaw Uncovered in French Supermarket Defrost Campaign:** Technical analysis of the cyber-physical incidents across French supermarket chains (including Intermarché) revealed that the unauthorized defrosting of cold-chain refrigeration networks did not require sophisticated zero-day exploits. Instead, threat actors systematically leveraged default, hardcoded credential schemas in Danfoss industrial refrigeration controllers, where administrative root passwords predictably defaulted to the current calendar date. The systematic exploitation of trivial authentication oversights on internet-exposed building management systems (BMS) underscores systemic hygiene failures across commercial operational technology (OT) logistics networks.
* **Vghost (CVE-2026-74580): Decade-Old Virtualization Flaw in Linux vhost Subsystem:** Tencent Zhuque Lab disclosed an AI-assisted discovery of a high-severity arbitrary memory read/write vulnerability in the Linux kernel vhost subsystem. The vulnerability enables an unprivileged local user to escalate to root permissions across kernel versions spanning nearly ten years. In specific hypervisor topologies, guest-to-host breakouts allow untrusted guest instances to write directly into host physical memory and hijack parent orchestration processes, exposing virtualized cloud infrastructure and private cloud ICS telemetry clusters to complete host compromise.
* **[UPDATE] Ivanti Connect Secure Zero-Day Attack Chain Exploits Architecture Defect (CVE-2026-104935):** Forensic updates regarding the active three-vulnerability chain targeting Ivanti Connect Secure VPN appliances indicate that vendor development teams had identified a constituent flaw during internal audits in June 2026 but deferred an out-of-band remediation. Threat actors subsequently weaponized the chain in the wild. Given that emergency mitigations currently address only two of the three flaws, edge appliances remain susceptible to memory disclosure and command execution if not strictly firewalled or isolated.
* **Critical Privilege Escalation in SAP Business Technology Platform Python SDK:** SAP published an urgent CVSS 10.0 security advisory affecting its Cloud SDK for Python within multi-tenant deployments on the SAP Business Technology Platform (BTP). Threat actors controlling a tenant subdomain can route OAuth2 client credentials directly to attacker-controlled listeners, resulting in lateral tenant compromise and the exfiltration of enterprise planning and supply-chain telemetry.

The proof-of-concept invalidates the core assumption that hardware-enforced memory isolation alone can protect high-value authentication secrets from targeted local compromise.
